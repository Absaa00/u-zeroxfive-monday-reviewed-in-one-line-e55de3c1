# Monday, Reviewed in One Line

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)

Entry for the make.fun competition [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) — one funny one-line review of my own Monday, under 200 characters, and nothing else.

## What it does

`main.py` is a small deterministic program with no network access. Run it and it prints exactly one line: my Monday review. No title, no explanation, no extra output — the review is the whole entry.

```sh
python3 main.py
```

Output:

> Monday ambushed me before my coffee woke up — I hit snooze five times and it still wrote me up for being late to my own life.

## Files

- `main.py` — the program; prints the single review line.
